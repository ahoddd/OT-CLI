# OrbTap i18n — How to add a new string

## Overview

- **Location:** `utils/i18n.ts` (logic), `constants/locales/*.json` (translations), `context/I18nContext.tsx` (React).
- **Usage:** `const { t } = useI18n();` then `t('section.key')`.
- **Fallback:** Missing keys fall back to English; in dev, missing keys are logged.

## Adding a new UI string

1. **Pick a key** (dot-separated, e.g. `screen.buttonLabel`).
2. **Add to English** in `constants/locales/en.json` under the right section (e.g. `"screen": { "buttonLabel": "Label text" }`).
3. **Add to other locales** in `constants/locales/es.json`, `ar.json`, `fr.json`, `pt.json`, etc., using the same key path.
4. **Use in code:**  
   `const { t } = useI18n();`  
   `<Text>{t('screen.buttonLabel')}</Text>`
5. **Interpolation:** For dynamic values, use `{{name}}` in the JSON and pass an object:  
   `t('auth.mustBeAge', { age: 13 })`  
   Translation: `"You must be at least {{age}} years old..."`

## Rules

- **Do not translate user-generated content** (names, bios, post text). Only translate app UI strings.
- Keep button labels short (e.g. ≤ ~22 chars) when possible to avoid overflow.
- Arabic: Prefer natural phrasing; RTL is applied when language is Arabic (app may need restart to apply layout).

## Supported locales

- `en` (default), `es`, `ar`, `fr`, `pt`, `de`, `it`, `hi`
- User can choose “System Default” or a specific language in **Settings → Language**.

## RTL (Arabic)

- When the user selects Arabic, `I18nManager.forceRTL(true)` is set. A modal prompts to restart the app so RTL layout takes effect.
- Use `const { isRTL } = useI18n()` if you need to adjust alignment manually: `textAlign: isRTL ? 'right' : 'left'`.
